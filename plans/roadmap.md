## 한 줄 목표

교사가 교과서 PDF와 스타일 레퍼런스를 주면, 차시별 핵심 내용을 공책정리 형태로 요약한 뒤 `ima2`로 레퍼런스 스타일에 맞게 변환해 최종 PNG/PDF를 자동 생성한다.

## 현재 활성 아키텍처 (v2)

```text
[0] intake
→ [1] extract
→ [2] lesson-spec
→ [3] draft-board
→ [4] stylize (ima2)
→ [5] deliver
```

- v2는 **중간 사용자 검수 없음**
- phase3은 텍스트 정확한 드래프트 보드를 만든다
- phase4는 `ima2`로 스타일만 입힌다
- 최종 산출물 기본 단위는 **차시별 PNG**

## 왜 v2로 바꾸는가

- 사용자가 직접 확인한 결과, `ima2`에
  - 스타일 레퍼런스 1장
  - 내용/구성 레퍼런스 1~N장
  - 역할이 분리된 프롬프트
  를 넣는 방식이 매우 잘 맞는다
- 따라서 기존의
  - 실제 이미지 소싱
  - 교사 승인 대기
  - HTML/CSS 최종 렌더
  중심 구조를 유지할 이유가 줄었다
- 이제 핵심은 **정확한 차시별 내용 보드 생성**과 **안정적인 `ima2` 프롬프트 자동화**다

## v2 단계별 핵심 산출물

### Phase 0 — intake
- `request.json`
- 스타일 레퍼런스 경로
- `ima2` 기본 설정

### Phase 1 — extract
- 교과서 전체 텍스트
- 차시별 텍스트 파일
- lesson/page 매핑 구조

### Phase 2 — lesson-spec
- 차시명
- 차시별 핵심 내용
- 공책정리용 블록 구조
- 이미지 프레임 내부에 넣을 설명문

### Phase 3 — draft-board
- 실제 텍스트가 정확히 들어간 차시별 요약 보드
- PNG/PDF 둘 다 가능
- 이미지 위치는 프레임으로 표시하고 내부에 설명문 삽입

### Phase 4 — stylize
- `ima2` 고정 설정:
  - 품질: `medium`
  - 크기: `1536x2048` (3:4)
  - 포맷: `png`
  - 모더레이션: `low`
  - 개수: `1`
- 레퍼런스 규칙:
  - `ref[0]` = 스타일 앵커
  - `ref[1]` = phase3 드래프트 보드
  - `ref[2..]` = 필요 시 교과서 보조 레퍼런스

### Phase 5 — deliver
- OneDrive로 차시별 PNG 배송
- 선택적으로 PNG 묶음 PDF 생성/배송
