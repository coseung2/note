# Agent: ima2-stylizer

**Phase**: 4 — stylize
**역할**: style reference + phase3 draft-board를 사용해 `ima2`로 차시별 최종 공책정리 이미지를 생성한다.

## 입력

- `phase0/request.json`
- `phase3/lesson_{NN}.png`
- `phase0/request.json`의 `style_reference_paths`

## 산출

```text
phase4/
├── lesson_01.png
├── lesson_02.png
├── requests.json
├── run.log
└── prompts/
    ├── 01.txt
    └── 02.txt
```

## 고정 설정

- 품질: `medium`
- 크기: `1536x2048` (3:4)
- 포맷: `png`
- 모더레이션: `low`
- 개수: `1`

## 레퍼런스 규칙

- `ref[0]`: 스타일 앵커
- `ref[1]`: phase3의 차시별 draft-board
- `ref[2..]`: 필요 시 교과서 보조 레퍼런스
- 현재 사회 5-1 2단원 주제2 이후 작업의 스타일 앵커는 사용자가 승인한 9차시 최종본을 우선 사용한다.
  - `OneDrive - 남선초등학교/학습자료/사회/공책정리/사회5-1_2단원_09차시_수도권에 인구가 집중하는 원인은 무엇일까요.png`

## 프롬프트 규칙

프롬프트는 아래 의미를 유지한다.

```text
1번 이미지를 최우선 스타일 레퍼런스로 사용한다.
2번 이미지는 내용과 레이아웃 레퍼런스다.
1번의 공책정리 분위기, 손그림 느낌, 색감, 여백 구성은 유지하고,
2번 이미지의 한국어 텍스트 내용과 섹션 구조를 보존한 채
학생용 공책정리 결과물로 다시 그려라.
이미지 프레임 자리에는 프레임 안 설명을 바탕으로 알맞은 삽화를 채운다.
텍스트는 한국어로 정확하게, 읽기 쉽게 유지한다.
2번 이미지의 한 문장 정리 빈칸은 그대로 빈칸으로 둔다. 정답, 초성 힌트, 답안 안내를 최종 이미지에 추가하지 않는다.
빈칸 문장의 앞뒤 문맥은 바꾸지 않는다. 정답을 노출하지 않아도 문장이 자연스럽게 읽혀야 한다.
내용과 무관한 다이어리식 장식은 넣지 않는다.
꽃, 별, 이파리, 반짝이, 랜덤 스티커 같은 장식 요소는 금지한다.
메인 타이틀 앞에는 기호를 붙이지 않는다.
메인 타이틀은 얇은 박스, 형광펜, 라벨 테두리로 감싸 강조한다.
기호와 작은 표시(◆, ◇, ✦, ▶, ※ 등)는 본문 안의 핵심 키워드나 섹션 소제목을 부각할 때만 제한적으로 사용한다.
```

## Primary Tool

**`ima2` CLI 또는 로컬 웹 UI**

예시:

```bash
ima2 gen --server http://localhost:3333 \
  --ref style.png \
  --ref phase3/lesson_01.png \
  -q medium -s 1536x2048 -o phase4/lesson_01.png \
  "1번 이미지를 최우선 스타일 레퍼런스로 사용한다. ..."
```

## 검증 게이트

- 모든 차시에 최종 PNG 생성
- 요청 수 == 차시 수
- `run.log`에 fatal error 없음

## 실패 처리

- 텍스트 깨짐 → same refs + 프롬프트 강화 후 재시도
- 스타일 반영 약함 → style reference 우선 문구 강화
- 내용 누락 → phase3 board를 두 번째가 아닌 첫 번째 보조 레퍼런스로 재배치해 재시도
