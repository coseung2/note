지형이 뭘까?

지형 : 땅의 생김새
우리 국토 : 산지 많음 + 삼면이 바다
산지에서 시작한 하천을 따라 평야가 펼쳐지고, 해안엔 모래사장·갯벌!

지형 용어 사전

산지 : 높고 낮은 산들이 모인 곳
하천 : 땅 위를 흐르는 크고 작은 물줄기
해안 : 바다와 육지가 맞닿은 부분
평야 : 평평하고 넓은 땅 (예: 김포평야)
섬 : 바다·강으로 둘러싸인 땅
갯벌 : 썰물 때 드러나는 진흙 땅

한강을 따라 떠나는 지형 여행 🚶

검룡소(강원도 태백시) → 남한강·북한강 만남(두물머리) → 서울특별시 → 황해로!
💬 "한강은 어디까지 이어질까?" ─ 산들이의 질문에서 여행 시작!
우리 국토에는 산지, 하천, 해안 등 다양한 지 형이 있다.

산지의 특징

국토의 약 70% : 산지 🏔
산맥 : 산봉우리가 길게 이어진 것
북쪽·동쪽 = 높고 험함
서쪽 = 낮아짐 (동고서저)
↑ 동쪽이 높고 서쪽이 낮다

하천 특징

지형 : 동쪽 높고 서쪽 낮음
큰 강은 동쪽 산지 → 황해/남해
상류 : 폭포·계곡 (빠르게 흐름)
하류 : 평야 발달 (벼농사 🌾)
↑ 상류→하류 흐름

주요 하천

  • 압록강 : 가장 긴 강. 한·중 경계
  • 두만강 : 북동쪽
  • 대동강 : 평양
  • 한강 : 서울 지남 → 황해
  • 금강 : 충남·전북 경계
  • 낙동강 : 태백시 → 남해
  • 영산강 : 담양 → 황해
  • 섬진강 : 남쪽
  • 청천강 · 임진강
💡 여주 평야의 쌀이 유명한 이유? ─ 한강 하류 평야의 비옥한 땅 덕!
💬 엄마: "이 지역은 예부터 벼농사로 좋은 쌀을 생산했단다."
우리나라 큰 하천은 대부분 동쪽 산지에서 시작해 황 해나 남해로 흐른다.

📜 우리나라 옛 자료

  • 세종실록 지리지(1454) : 무릉과 우산은 울진현 정동쪽 바다
  • 팔도총도(1531) : 울릉도·독도 그림
  • 동국대지도(18C) : 작은 섬 독도 그려짐
  • 대한제국 칙령 41호(1900) : 석도(독도)를 울도군 관할

🌏 다른 나라 자료

  • 일본 삼국접양지도(1785) : 독도 = 조선 영토 색
  • 일본 태정관 지령(1877) : 독도는 일본과 관계 없음
  • 프랑스 조선왕국전도(1737) : 조선 영토로 표시

🛡 독도를 지킨 사람들

이사부 : 신라 장군, 우산국 정복

독도 의용 수비대 : 울릉도 청년들
최종덕 : 최초 독도 주민
